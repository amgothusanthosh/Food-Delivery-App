# Food Delivery App

A web-based food delivery application designed to make browsing food items and placing orders simple and convenient.

## Features
- User registration and login
- Browse food items and restaurants
- Add and remove items from the cart
- Manage orders
- Responsive user interface

## Tech Stack
- Frontend: React.js
- Backend: Node.js and Express.js
- Database: MongoDB
- Version Control: Git and GitHub

## Installation and Setup

### 1. Clone the repository
```bash
git clone https://github.com/amgothusanthosh/Food-Delivery-App.git
cd Food-Delivery-App
```

### 2. Install dependencies
Install dependencies separately in the frontend and backend directories:

```bash
cd backend
npm install
```

Then open a second terminal:

```bash
cd frontend
npm install
```

### 3. Configure environment variables
Create a `.env` file in the backend directory and configure the required database connection string, port, and authentication secret. Never commit secrets to GitHub.

### 4. Run the application
Use the scripts defined in each directory's `package.json` to start the backend and frontend.
